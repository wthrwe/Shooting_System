# 云台项目调试复盘日志
记录项目调试过程中遇到的故障、排查思路、根因与解决方案。

| 现象 | 排查思路 | 根因 | 解决方案 |
| ---- | ---- | ---- | ---- |
| 云台在目标中心点附近持续小幅抖动、电机嗡鸣 | 打印视觉原始cx/cy坐标，观察目标静止时像素跳动范围 | YOLO输出目标框中心存在2-4px固有像素抖动，直接进控制环造成频繁换向 | 引入8px死区，偏差小于死区时输出转速0，抑制抖动 |
| 串口接收偶现错乱帧，解析出异常坐标 | 模拟高速发送，观察缓冲区读写行为，复现帧撕裂现象 | 使用普通线性缓冲区，中断写入与任务同时读取发生帧撕裂 | 替换为单生产者单消费者1024字节环形缓冲区；满时丢弃新来字节保护正在读取帧；增加行解析逻辑 |
| 高流量串口输入时心跳日志不再输出，系统看似死机 | 分析任务优先级，观察各任务调度情况 | VisionTask是系统最高优先级，如果循环读到缓冲区为空才退出，灌垃圾数据会一直占用CPU，饿死低优先级心跳任务 | VisionTask每轮最多解析16行，剩余数据留给下一个控制周期处理，保障低优先级任务可以得到调度 |
| 大偏差下云台转速过高，发生明显过冲来回震荡 | 打印P输出转速，观察大偏差时输出数值 | 纯比例控制，大像素偏差输出转速过高，机械惯性造成过冲 | 增加转速限幅 ±2rpm，大偏差场景限制最大跟踪速度 |
| 重新用CubeMX生成工程，云台运动异常，无编译报错 | 对比前后TIM寄存器日志，启用[TIM]开机寄存器自检 | CubeMX重生成工程静默修改PWM定时器配置，代码逻辑不变硬件输出异常 | 增加开机定时器寄存器逐项自检[TIM]，发现配置异常可以通过日志直接定位 |
